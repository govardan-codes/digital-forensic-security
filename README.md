### 🌟 Overview
**Digital Forensic Security** is a secure web-based platform designed for digital evidence handling, analysis, and forensic investigation. It ensures chain-of-custody, evidence integrity, and tamper-proof logs.

Built with ❤️ for Cybersecurity Enthusiasts and Forensic Investigators.

### 🚀 Key Features
- 🔐 **Secure Evidence Upload** - Tamper-proof file handling with hash verification (SHA256)
- 🕵️ **Forensic Analysis Engine** - Automated analysis in `helpers/` & `utils/`
- 📝 **Immutable Logs** - Every action tracked in `/logs` for court-ready audit
- 🧠 **AI Models Integration** - Models stored in `/models` for anomaly detection
- 📂 **Case Management** - Routes in `/routes` for clean case segregation
- 🎨 **Modern UI** - Responsive templates in `/templates` & `/static`

### 🏗️ Tech Stack
| Layer | Technology |
| :--- | :--- |
| **Backend** | Python, Flask, `app.py`, `config.py` |

| **Security** | Hashing, .env protection, Secure Uploads |
